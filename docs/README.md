## 過去資料と調査資料

2026-10-20 に、直下の過去レビュー・改善提案・パッチと `issues/` のエクスポート・下書きを `archive/` に移しました。
これらは作成時点のブランチ・コミットに対する記録です。現在の実装、GitHub issue の状態、完了状況を示すものではありません。
たとえば過去資料の「テストなし」「143 tests」「5 bundle」や、現在存在しないモジュールへの参照は現行仕様として扱わないでください。

- `archive/`: 以前のレビュー、実装案、issue メモ。履歴を削除せず保管しています。
- `research/`: 設計・配信サービス等の調査資料。現行の動作保証や未解消問題の一覧ではありません。
- `siteHtml/`: DOM 調査用に保存したページとその付属ファイル。

現行の案内であるこのファイル・`recording-and-sync.md`・`testing.md` は Git 管理対象です。
履歴・調査・保存ページは従来どおりローカル資料として Git 管理外に置いています。ローカル資料へのリンクには依存せず、上の2文書から実装とテストを確認できます。
